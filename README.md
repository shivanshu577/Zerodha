# Zerodha Clone

A full-stack web application cloning core functionalities of the Zerodha trading platform. This project includes a user-facing landing/marketing site, an interactive trading dashboard, and a backend server to handle data and APIs.

## 🚀 Features

* **Landing Page (`/frontend`):** Marketing and informational pages built with modern React components.
* **Trading Dashboard (`/dashboard`):** Interactive UI for viewing stock portfolios, watchlists, positions, and analytics.
* **Backend API (`/backend`):** Server handling API endpoints, data persistence, and application logic.

## 🛠️ Tech Stack

* **Frontend & Dashboard:** React.js, HTML5, CSS3, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB / Mongoose
